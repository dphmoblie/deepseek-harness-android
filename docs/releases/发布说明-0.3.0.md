# 0.3.0 正式版发布说明

## 本版重点

- 修复 Harness 停止、重启、返回管理页和悬浮球展开之间的授权生命周期竞态。
- 运行周期结束时撤销旧的 Harness 凭据，避免旧页面或悬浮球重新使用失效会话。
- 发布包补充 PRoot/Operit、Ubuntu `git` 对应源码和构建安装材料，并在发布后重新校验归档完整性。

## 验证范围

- Android JVM 单测、Lint、团队签名 Debug/Release APK 装配通过。
- 真机覆盖安装、运行环境更新、Harness 打开、返回管理页和会话标题读取已验证；设备 page-size 为 4096 字节。
- 发布工作流的 Ubuntu 源码归档步骤需由 GitHub Actions 的 Ubuntu runner 执行验证。

# 0.4.2 发布说明（测试版）

本版是当前 `main` 的测试版构建。功能代码与主分支一致，仅提升版本号并重新生成 APK 与运行环境；
用于验证 0.4.1 之后的多语言、任务通知与运行时交互修复。

## 相对 0.4.1 的主要变化

- **界面语言**：新增繁體中文、日本語、한국어。语言白名单、原生偏好、通知与悬浮球文案、
  资源翻译同步更新；切换语言后设置页、通知与 Harness 运行时映射保持一致。
- **任务通知**：通知栏显示 AI 运行状态，并适配系统实时动态；进程被系统回收后撤下过期状态，
  不再留下一条「正在运行」的空通知。
- **悬浮球**：优化拖动流畅度，开关状态持久化。
- **运行时更新**：
  - 更新/安装失败或超时的原因不再被确认对话框遮住（提示条层级修复）；
  - 外部操作仍在进行时点「确认更新」会明确提示，而不是静默无响应；
  - 版本页读取 Harness 版本列表期间不再允许启动/打开对话，避免原生返回
    `RUNTIME_OPERATION_BUSY`；
  - 运行时更新保留数据的搬移与取回校验更严格，防止误删与漏取。
- **诊断日志**：默认开启采集（从未设置过的设备）；用户显式关闭过的仍保持关闭。
  设置页说明、设计文档与四语言翻译同步。
- **稳定性**：补充通知、版本列表与更新对话框的回归用例，修正多语言契约断言。

## 验证

- 本机：`tsc -b`、ESLint、`node scripts/gate-check.mjs` 4/4；
  前端版本管理、更新对话框、诊断日志与 i18n 相关用例全过。
- 发布流水线会重新执行前端、脚本、Android JVM 单测、签名 APK、rootfs 与资产校验；
  以 Release 中实际产出的 `app-release.apk`、`rootfs.bundle`、`runtime-manifest.json` 为准。

## 安装

1. 安装 `app-release.apk`（离线 APK，已内置 PRoot 运行器与 Ubuntu rootfs）。
2. 首次打开后按引导安装运行环境；rootfs 从 APK 内置资产解压，无需联网下载。
3. 旧版本升级时可保留已有会话与工作区；运行环境更新/回退的保留项见版本管理页。

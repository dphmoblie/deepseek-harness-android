# 0.3.8 发布说明

## 旧版 Android 的语言引导

- 修掉「旧机上语言引导没有继续按钮」。根因不是缺纯色兜底，而是 `color-mix()` 声明里带 `var()`：
  旧引擎在**计算值阶段**判无效，该声明仍然赢下级联、等价 `unset`，按钮底色直接变透明。
  现在全部 64 条 `color-mix` 声明都移进 `@supports (color: color-mix(in srgb, red, blue))`，
  原位保留纯色；新增门禁 `src/legacyWebViewCss.test.ts` 同时校验「不许漏网」「每条都有同选择器
  同属性的兜底」「样式文件花括号必须平衡」（少一个 `}` 会让浏览器静默丢弃整份样式表的剩余部分）。
- 自定义强调色与文字色不再往 DOM 写 `color-mix()`，改成 `rgba()`（`src/ui/cssColor.ts`），
  `index.html` 的首帧脚本同步修改并重算了 CSP 哈希。
- 语言的真值改以原生偏好为准：新增桥方法 `getAppLanguage`（带 `configured` 区分「用户选过」与
  「回落 zh-CN」），本地存储被清空时回填后直接跳过门禁；探测期间显示启动页，不再闪一下选择框。
- 门禁留软出口：选中即提交，并新增「跳过，使用简体中文」；本地存储写不进去时也让本次会话进入应用，
  只在设置页提示「下次启动可能再次询问」。
- 不支持 `color-mix` 的系统 WebView 会在设置首页看到一句明确说明（应用侧装不了这个系统组件）。

## 模型与密钥

- 二级页只列**已经配置过**的供应商；未配置的模板收进新的三级页「添加其他供应商」，
  点一家即回到模型页并展开它的密钥输入。
- 「获取模型」默认只展开最靠前的一条，其余折在「显示全部 N 个」后。

## 设置与版本管理

- 「外置浏览器」从诊断页拆成独立二级页，诊断页只留入口行。
- 「版本管理 → 在线可用版本」默认只显示一个可用版本（本地版本库仍保留 3 条折叠）。
- 修复窄屏下「设备 Shell 卡片」内的按钮被排进 40px 图标列、文字逐字竖排的问题。

## 兼容与门禁

- 新增 `src/legacyWebView.ts`：`color-mix` 能力探测，只用于提示，不做自动修复。
- 前端门禁：`tsc -b`、`eslint --max-warnings 0`、979 条 vitest 全绿（含新增的 CSS 兼容门禁与语言门禁用例）。
- 原生：`compileDebugKotlin` 与 `testDebugUnitTest` 通过；桥接对等性测试覆盖新增的 `getAppLanguage`。

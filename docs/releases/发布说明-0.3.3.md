# 0.3.3 更新说明

## 本版重点

- **应用选择器新增「搜索」按钮**：点按钮或按回车立即按输入框当前原文查询，不再只依赖 200 ms 防抖与输入法的 `compositionend`；拼音候选未提交时也能搜。
- **背景状态提示更可靠**：保存/清除背景时记录一个轻量标记；读取本地背景失败时不再把已选背景误报成「未选择」。
- **副屏设置会被记住**：离开副屏设置页时自动保存未落盘的改动；启动副屏时把方向、自适应、预览档位、自动跟随与自定义尺寸一并写回偏好，重进页面不再回到旧值。
- **修复 Harness 模型页保存凭据失败**：凭据文档兼容 `refs: {}` 空映射与未知顶层段（与 dsh 自身口径一致），不再因解析拒绝而回落到环境变量，从而出现「引用只读、保存失败」。
- **视频壁纸冷启动不再变黑**：外壳 WebView 允许静音自动播放，冷启动后视频壁纸能继续播放。
- 合并外部文件分享相关加固：分享/打开动作、外部文件缓存上限与生命周期处理。

## 升级提示

本版包含 Ubuntu 运行环境内的 DSH 前端样式修复，只覆盖安装 APK 不会更新已解压的运行环境。升级后请在应用提示时确认更新运行环境。

**更新运行环境会替换其中的本地修改。请先另行备份重要数据；程序的自动保留与恢复机制不能代替完整备份。**

## 验证限制

前端 959 项测试通过，脚本 342 项通过（4 项因平台限制跳过），`tsc`、ESLint、生产构建与 `gate-check` 通过；Android Kotlin 编译与 JVM 单元测试通过。

副屏拖动手感、壁纸冷启动表现与搜索按钮在输入法组合态下的行为属于真机行为，本版只做到代码与单元测试层面的验证，需要真机复测确认。

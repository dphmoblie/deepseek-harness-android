# 0.4.5 发布说明（测试版）

本版是当前 `main` 的测试版构建。功能代码与主分支一致，仅提升版本号并重新生成 APK 与运行环境；
本次重点验证根通道高危操作授权、运行时自检收敛与旧 WebView 兼容修复。

## 相对 0.4.4 的主要变化

- **根通道与 AI 高危权限**
  - 新增 AI 高危文件与命令权限总开关，以及 17 项细分拦截规则。
  - 根命令按四级风险分类：低风险直接放行；提升风险在 `strict` 档走 dsh 官方审批；
    高风险与严重风险必须打开应用警告确认页并完成系统身份确认。
  - `maximum` 档不再做静态硬拦截，但访客无法自报批准绕过应用确认页；
    会话处于 `danger-full-access` 时按 dsh 授权处理，不重复弹审批。
  - 加固根命令并发、桥接与恢复边界，避免授权状态在异常路径被放大或丢失。
- **运行时自检**
  - 自检载荷调整为 17 项（访客 13 项 + 宿主 4 项），移除没有行动价值的硬链接探针，
    避免每次都在自检面板固定报一条红项。
  - `write`/附件落盘仍走已回退的 `rename` 路径；失败时按 dsh 原始错误排查。
- **旧 WebView 兼容**
  - 旧内核用例增加 `onPageFinished` 兜底注入，修复页面脚本注入时机过早导致的缺失。
- **应用内配色与通知**
  - DSH 页面的文字与底色改为同源：文字调色板按外壳实际铺上去的面板亮度决定，
    不再由页面的 `prefers-color-scheme` 单独翻面，修复「白字深底配黑字」与「黑字压深底」。
  - 主题在 document-start 注入，首帧即一致；body 重建、页面重放主题时自动对齐，
    取消同步会撤注册并把页面还原。
  - 关闭 WebView 算法加深；前台服务通知只对齐强调色，文字颜色仍交给系统，避免另一半
    系统主题下不可读。
- **文档**
  - README 五语文档刷新，补充最新功能与本地化说明。

## 验证

- 发布流水线会重新执行前端、脚本、Android JVM 单测、lint、签名 APK、rootfs 与资产校验；
  以 Release 中实际产出的 `app-release.apk`、`rootfs.bundle`、`runtime-manifest.json` 为准。

## 安装

1. 安装 `app-release.apk`（已内置 PRoot 运行器与 Ubuntu rootfs）。
2. 首次打开后按引导安装运行环境；rootfs 从 APK 内置资产解压，无需联网下载。
3. 旧版本升级时保留会话与工作区；根通道高危操作需要按应用内警告页确认。

## 已知限制

沿用 [0.4.0 发布说明](发布说明-0.4.0.md) 中的已知限制；根通道、副屏与国产 ROM 的
应用列表权限仍需按机型复测。

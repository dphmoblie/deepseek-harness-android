# 0.4.1 发布说明（测试版）

本版是当前 `main` 的测试版构建。功能代码与主分支一致，仅提升版本号并重新生成 APK 与运行环境；
用于验证 0.4.0 之后的会话分组、运行数据保留与外置浏览器鉴权修复。

## 相对 0.4.0 的主要变化

- **外置浏览器双层鉴权**：Android 从已校验的启动 URL 直接取出 dsh 启动令牌，和应用自己的
  `dshMobileToken` 一起交给预载；预载按完整 `dsh web:` 行识别令牌，插件日志里的 `token=`
  不再能抢占。预载会随 APK 原子刷新到已安装/回退的运行时，不必先重装运行环境；拿不到令牌时
  给出可重试提示，而不是把浏览器送进 dsh 的 401 页。
- **会话列表**：子代理按父会话折叠，默认只看主会话，支持主会话 / 全部 / 子代理筛选；标题与
  子代理预设名都参与搜索。父会话被列表上限截断时，子代理进入「未关联」而不是静默消失。
- **运行环境更新与回退**：保留 `root` 用户空间，合并同名文件与目录；冲突项留在 `preserve-*`
  目录并在版本页可见，修复提升中断后的恢复路径。
- **设备工具与界面**：设备桥/PTY 文档与输入边界更新；文件预览分享使用工作区绝对路径；
  DSH 右栏全屏时撤掉收起态导轨，避免鲸鱼入口压住右栏标签条。

## 验证

- 推送 CI：`4b63510`（当前 `main` 基线的构建与校验）通过。
- 本版发布流水线会重新执行前端、脚本、Android JVM 单测、签名 APK、rootfs 与资产校验；
  以 Release 中实际产出的 `app-release.apk`、`rootfs.bundle`、`runtime-manifest.json` 为准。

## 安装

1. 安装 `app-release.apk`（离线 APK，已内置 PRoot 运行器与 Ubuntu rootfs）。
2. 首次打开后按引导安装运行环境；rootfs 从 APK 内置资产解压，无需联网下载。
3. 旧版本升级时可保留已有会话与工作区；运行环境更新/回退的保留项见版本管理页。

## 已知限制

# 0.3.5 更新说明

## 本版重点

- **诊断页新增「打开方式」**：可以把「用外部浏览器打开 Harness」固定到某一个已安装浏览器，
  不再每次都经过系统选择器；选择会持久保存，也可以改回「每次询问」。固定浏览器被卸载后
  自动回退到系统选择器，不会留下一个点不动的选项。
- **官方文档预览顶栏新增「分享」**：预览文档、图片、PDF 等文件时，顶栏最右侧会出现分享按钮，
  点击后直接调起系统分享面板。分享范围严格限制在内置工作区 `root/1` 下的普通文件；
  页面传来的路径会由原生重新解析并按 NoFollow 规则校验，工作区外的绝对路径、目录跳转和
  编码斜杠一律拒绝。

## 升级提示

- 本版只有 APK 侧改动，运行环境内容没有变化；更新运行环境仍会替换其中的本地修改
  （用 apt 等装进系统的软件等），重要数据请先另行备份。
- 固定浏览器后，如果该浏览器不支持 Harness 所需的内核能力，分享与页面功能可能异常；
  此时把「打开方式」改回「每次询问」即可重新选择。

## 验证限制

- 前端测试、脚本测试、`tsc`、ESLint、生产构建、`gate-check` 与 Android JVM 单元测试通过；
  Kotlin 编译无错误。
- 「打开方式」与预览顶栏「分享」都属于 WebView/系统面板交互，需在真机安装测试版后复测：
  诊断页能列出已安装浏览器并记住选择；预览面板顶栏出现分享按钮，点击后能调起系统分享面板。

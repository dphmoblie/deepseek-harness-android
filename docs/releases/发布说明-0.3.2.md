# 0.3.2 更新说明

## 本版重点

- 设置页不再有「保存」按钮：输入期间不落盘，离开这一页或切到后台时自动保存一次，草稿在本次应用会话内一直保留。
- 主题设置新增「按钮与输入框」不透明度，按钮与输入框共用同一份值；「选中的强调色」单独一组。
- 主题下新增「DSH 主题」三级页：按钮/输入框透明度、让 DSH 使用当前主题、恢复默认，以及连背景一起同步与背景文件选择都收在这一页。
- 修复同步到 DSH 的主题与背景不生效、不显示：底色改由 `html` 承担、`body` 透明，背景层不再被盖住；同步色接进官方面板与按钮令牌。
- 「后台」页直接呈现后台保持、悬浮球、预启动与运行时/设备 Shell 入口，取消原来的两个三级页。
- 背景设置不再显示「未选择文件」：改为按已保存的背景显示真实状态；副屏页记住上次选中的目标应用，会话结束后重进仍会回填。
- 副屏：小窗缩放手柄改为深底白描边，浅色应用上也能看见；小窗启动后立即置前，不必先点一下画面。
- 副屏中文输入的剪贴板通道：确认可用后不再重复读回剪贴板（少一次 shell 往返），粘贴前先请求焦点并在被拒时重试。

## 升级提示

本版包含 Ubuntu 运行环境内的前端样式修复（DSH 主题与背景），只覆盖安装 APK 不会更新已解压的运行环境。升级后请在应用提示时确认更新运行环境。

**更新运行环境会替换其中的本地修改。请先另行备份重要数据；程序的自动保留与恢复机制不能代替完整备份。**

## 验证限制

前端 949 项测试通过，脚本 342 项通过（4 项因平台限制跳过），`tsc`、ESLint、生产构建与 `gate-check` 通过。Android 侧 Kotlin 编译与 JVM 单元测试通过，APK 内置运行时归档的大小与 SHA-256 校验通过、原生库 16 KB 对齐通过。

副屏小窗的缩放手柄、启动置前与剪贴板粘贴成功率属于真机行为，本版只做到代码与单元测试层面的验证，需要真机复测确认。

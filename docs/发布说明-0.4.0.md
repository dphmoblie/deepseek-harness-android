## 应用列表权限（国产 ROM）

- 清单新增 `com.android.permission.GET_INSTALLED_APPS`：国产 ROM 按
  T/TAF 108-2022 在 `QUERY_ALL_PACKAGES` 之外额外管控「读取应用列表」，缺少它时
  `getInstalledApplications` 可能只返回本应用。AOSP / Pixel / 三星没有这条权限，
  此时视为已授予，界面不显示授权入口。
- 原生桥新增查询与申请两个方法；白名单选择器与副屏原生选择页**照常读取清单**，只有列表
  真的只剩本应用时才说明原因，并提供「授予权限 / 打开应用设置」。列表读得全时不会主动
  要求授权。
- 实测荣耀 MagicOS 11 / Android 17：`QUERY_ALL_PACKAGES` 已能读到 482 个应用；声明该权限
  后系统弹窗文案为「是否允许『读取设备应用列表』？」，与小米 / 荣耀的权限页开关对应。

## 页面网络访问与内置插件市场

- 设置新增「网络访问」三档（仅本应用内 / 允许 HTTP 连接 / 全部网络连接），默认只连本机；
  档位只放开页面自己发起的 http(s) 请求，主框架导航、file/content 协议与带 userinfo 的
  地址任何档位都不放行。
- 档位写入原生偏好，对话页与悬浮球小窗逐请求读取；未知值直接拒绝，缺键按最严档处理，
  环境详情按实际档位显示。
- `dshmarket` 作为内置插件市场随运行时打包，CI 校验其许可证并在运行时树里实际加载。

## 根通道分档与电源动作

- 根通道改为 `off` / `read_write` + `strict` / `maximum` 两档；最大档只拦刷机、块设备、
  核心分区写入、数据销毁、电源与物理内存，严格档继续拦 `mount` / `dd` / `insmod` /
  `setprop`。
- 危险命令改为按命令位置与参数路径匹配，换行按命令起点处理，支持 `busybox` 与绝对路径前缀。
- 手动重启 / 关机移回设置页，需先通过系统身份确认；设备桥与 AI 工具不暴露电源命令。

## 旧版 WebView 与更新链路

- 补齐旧内核缺失的 `toSorted` / `toReversed` / `toSpliced` / `with`、`Promise.withResolvers`
  与 `URL.canParse`：ColorOS 13 一类旧 WebView 打开模型列表不再报
  `groups.toSorted is not a function`。
- 长操作（安装 / 修复 / 版本切换 / 插件安装 / 运行库下载）期间，启动请求快速失败并返回
  `RUNTIME_OPERATION_BUSY`，不再排队到安装结束后把 Harness 拉起来。
- 应用更新默认检查远端最新版，并保留原生缓存默认行为；测试频道选择在主存储缺失或损坏时
  从冗余副本恢复；预览分享优先使用标题栏的绝对路径。
- AI 可直接启动并管理目标应用副屏，沿用既有副屏会话与工具。

## 已知限制

- 副屏仍是实验功能：完整 Shizuku 授权与绑定链路、真实第三方应用、小窗互切与长期后台
  未在全部机型复测。
- 根通道沙箱在实测设备上是降级的（SELinux / 框架限制），界面如实显示；`maximum` 不等于
  完整隔离。
- 国产 ROM 的应用列表管控差异较大：有的只需 `QUERY_ALL_PACKAGES`，有的需要
  `GET_INSTALLED_APPS`；选择器只在列表确实只剩本应用时才提示授权。

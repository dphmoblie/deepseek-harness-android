# 0.3.7 发布说明

## 主题同步

- 主题令牌改到 `html[data-dsh-theme-source='shell'] body`：官方调色板把同名 `--dsw-alias-*` 声明在 body 上，
  写在 html 上不会传给任何面板（此前「同步了主题但 DSH 不变」的根因）。
- 面板层跟随「面板/卡片不透明度」，按钮与输入框跟随「按钮与输入框不透明度」。
- 壳的深/浅同步到官方 `body[data-ds-dark-theme]`。
- 背景媒体：html 透明、背景层 `z-index:-1`，视频固定 `position:fixed`——修复「背景盖住整个 UI」。
- 主题页按钮与搜索框跟随强调色。

## 外置浏览器

- 入口参数改为 `dshMobileToken`，不再抢占 dsh 自己的 `?token=`。
- 302 使用绝对 Location；预载截获 dsh 打印的令牌，交接时一并带上，双层鉴权一次通过。
- 交付改为系统选择器。

## 兼容与稳定性

- 补齐旧 WebView 的 AbortSignal EventTarget（目录选择不再报 `signal.addEventListener is not a function`）。
- 密钥输入框补 `onInput/onPaste/onCompositionEnd`，修复输入法粘贴后识别不到内容。
- 上游 Harness 安装：npm 超时 240s → 900s、重试 3 次、超时 120s，失败输出带 exit/signal 摘要。

## 修复

- 网络安全配置去掉重复的 domain-config：修复 Shizuku UserService 进程启动时的
  `Found multiple conflicting per-domain rules` 崩溃。
- 发布版关闭资源裁剪与 R8 混淆（体积 98% 是 rootfs，混淆只会让 Shizuku/FileProvider 的按名调用出错）。

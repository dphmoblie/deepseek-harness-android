# 0.2.14 发布说明

本版重排设置页：搜索删掉、卡片不超两屏、运行与后台并为「后台」、启动权限交回 dsh；供应商与
密钥合成一处；文件管理合并为「外部工作区」；版本清理合并；副屏能收起也能读输入法文字；
更新包下载有进度条。

## 一、设置页结构（需求 1、8、9、10、11）

- 设置首页的搜索框与检索逻辑整体移除，设置项按分组浏览。
- 每个设置卡片最高「手机上看得见的那块 ×2」，超出部分在卡片内部滚动（`overscroll-behavior:
  contain`），惯性不再带着整页跑。
- 首页最上方那一格从「应用设置」改成「停止 Harness 服务」，只在运行中可点；应用设置入口
  仍在顶部图标与底部导航里。
- 「运行与后台」改名「后台」：顶部是「Ubuntu 运行时」与「设备 Shell 设置」两个入口（各自的
  独立页保留），「运行时来源」的清单地址与 SHA-256 并进同一段。
- 「Harness 启动权限」整体删除：界面上不再有这一项，启动时也不再注入 `DSH_PERMISSION_MODE`，
  会话权限完全交给 dsh 自己的权限预设。运行时自检从「后台」搬到「诊断与日志」。
- 「插件管理」只保留在底部导航，不再出现在设置页里。

## 二、供应商与密钥（需求 3、4）

「清除密钥」与已配置供应商合并成一个入口：能看到已配好的模型供应商，也能在同一个地方改
地址与 API Key。0.2.x 早期只有「清除密钥」，配过的供应商在界面上看不见，这一版按需求合并。

## 三、设备 Shell 与自动化（需求 6、7）

- 「终端与设备 shell」改名「设备 shell」；Shizuku 与 AI Shell 收进「设备 shell 设置」二级页。
- 无障碍与副屏统一进新的「自动化设置」一级页，各自二级页；免责说明只占一条，点开是详情；
  自动化的参数与规则按无障碍、副屏分开。
- 输入时界面整体让出输入法遮挡的高度：`visualViewport` 量出被遮挡的像素写进
  `--keyboard-inset`，壳子底部让位，终端与对话框一起抬起来，输入框最下端贴在输入法框上沿。

## 四、主题与字号（需求 5）

「终端与外观」整合为「主题」，主题页的「字号」现在管**整个应用壳子**：CSS 里以 rem 写的字号
随根字号缩放（原来 7 处 px 字号按 16px 基准换算成 rem）。字号保持默认值 14 时界面与改动前
逐像素一致（缩放系数 1）；dsh 自己界面的字号仍由 dsh 自己设置，应用不碰。

## 五、文件管理：外部工作区（需求 12）

「投递区」与「共享目录」不再分别出现，统一叫「**外部工作区**」：一个文件浏览器，一张卡里
「搬运」与「目录」两块，中间的搬运说明与目录白名单提示按新名字改写。目录都是访客能看到的。

## 六、版本管理（需求 13）

数据清理与运行时清理合并到一处，去掉「设备能力」卡片，取消「从 GitHub 安装版本」的入口；
应用更新包下载现在显示进度条（原生按总量节流上报，最多 100 步，末笔一定上报）。

## 七、副屏（需求 14、15）

- **读得到输入法打的字**：节点树 dump 时额外带一份 `imeText`，从输入法窗口自己的根节点取
  （最多 120 个节点、6 层、120 字），优先取「可编辑且聚焦」的候选；密码输入框跳过。
- **有出口**：悬浮窗上有「收起」与「结束」，设置页里打开的预览页有「返回」，预览与悬浮窗
  用的是同一套控件。默认系统画中画的方案本版未做（见「未验证」）。

## 八、自动启动修复（需求 2）

关掉「自动启动 Harness」之后不再被拉起：判据从「设置已读完且为 false」改成「设置未读完或
不是 true 都直接返回」，设置晚于运行时就绪也不会启动。

## 九、验证范围

- 本机前端：`npx vitest run` 53 文件 / 707 用例 / 0 失败；`npx tsc -b` 与
  `npx eslint . --max-warnings 0` 退出码 0；`node --test scripts/*.test.mjs` 295 项
  （291 通过 / 4 跳过 / 0 失败）。
- 本机 Android：`:app:testDebugUnitTest` 132 个测试类 / 1318 条用例 / 0 失败 / 27 跳过
  （跳过项需要真机或更高版本 SDK），`:app:lintRelease` 通过，`BUILD SUCCESSFUL in 2m 21s`。
- 上游 CI（构建 + 验证）以最终结果为准，见仓库 Actions 记录。

## 十、未验证与已知问题

- 上述 15 条需求都**没有在真机上逐条复测**：副屏能不能真读到输入法文字、悬浮窗的收起与结束
  在真机上的手感、输入法让位在华为/小米上的实际高度、字号缩放在大屏上的观感，都要装到手机上
  才能确认。
- 副屏「默认系统画中画」本版**未做**：按你选的方案，本版先做「可调大小 + 退出按钮 + 预览与
  悬浮窗内容一致」，PiP 留到下一版。
- 0.2.13 及更早列出的真机未验证项依旧未复测。

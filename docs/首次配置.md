# 首次配置

装好 APK、打开应用，会出现一个两步的窗口：**配模型 → 装运行环境**。

两步互不依赖，随时可以关掉去用别的功能（右上角 ×）；下次启动会再次弹出，直到点「完成」或 × 关掉为止。配到一半想改，用「上一步」回去，已经输入但还没保存的内容不会丢。

## 第一步：配模型

1. 把 DeepSeek 的 API Key 粘进输入框。
2. 点「保存 API Key」。

窗口只做两件事：配置 API Key、安装运行环境。这一页只收 API Key，别的一概不在这里设，装好之后自己按需调整即可。

**首次配置不遮罩密钥。** 输入框里显示的就是真实内容——这是故意的：遮罩会让人看不出输入法补字、折行、粘贴丢字。输入框下方实时显示「已输入 N 个字符」，粘进来的内容如果带了空格、换行、`Bearer ` 前缀或外层引号，会被自动去掉并提示一句。

保存成功后才清空输入框；保存失败或正在忙，内容原样留着，直接重试即可。保存后的密钥不会再完整显示。

**其它供应商**（自建 OpenAI 兼容端点、中转站、别的厂商）不在首次配置里选：装好运行环境后去**设置 → 模型与密钥**添加。

## 第二步：装运行环境

应用需要一份 Ubuntu 运行环境才跑得起来。装一次就够，之后离线可用。

- **官方 APK**：镜像已经打包在里面。点「安装运行时」，等进度走完，全程不需要联网。
- **自行构建的 APK**：通常没有打包镜像，点「安装运行时」会失败。改点「安装失败？去在线下载其它版本」，会跳到「版本管理」：在「在线可用版本」里选一条点「下载到版本库」，下完在「本地版本库」里点「切换至此版本」。建议连 Wi-Fi，体积有好几百 MB。
- 现在不想装，点「完成」就行，第一步配好的凭据不会受影响；运行环境以后随时能在**设置 → Ubuntu 运行时**里装。

两步走完窗口就结束了：凭据和运行环境都齐了，回主界面点「打开对话」就能开始。

## 配不上时

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 输入框里看着有内容，保存按钮却是灰的 | 内容里没有可见字符（只剩空格或零宽字符，被清理掉了） | 重新粘贴一次 |
| 保存成功、再回到第一步，输入框是空的 | 正常：密钥已保存，不再回显 | 不用重填；状态行会显示「已配置」 |
| 点「保存 API Key」提示未能保存 | 写入失败（存储异常等），输入已保留 | 直接再点一次；反复失败去「日志与排查」看诊断日志 |
| 「安装运行时」失败 | 这份 APK 没内置镜像 | 走「安装失败？去在线下载其它版本」 |
| 「在线可用版本」是空的，或提示连不上 | 网络不可达或镜像源暂时取不到 | 换网络后点右上角刷新；已下载过的版本在本地版本库可离线切换 |
| 打开 Harness 后提示没有模型凭据 | 应用只认本机保存的凭据，判断不了它是否有效 | 回**设置 → 模型与密钥**确认已配置，再重开 Harness |

第一次配置的密钥由 Android Keystore 保护，写入 Harness 私有的 `~/.dsh/.credentials.yaml`（0600），不回传 WebView。细节见 [架构与安全边界](ARCHITECTURE.md) 与 README 的「模型供应商」一节。

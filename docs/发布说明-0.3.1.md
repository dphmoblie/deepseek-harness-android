# 0.3.1 更新说明

## 本版重点

- 修复 Issue #18：外部浏览器的精确 GET `/oauth/callback` 可以到达 Harness，由官方账号模块校验 state、PKCE、有效期和重放；其他页面与 WebSocket 继续要求应用认证。
- Android 支持官方登录弹窗的空白页预打开及异步授权跳转，仅将固定 DeepSeek 官方授权端点交给系统浏览器，不向浏览器传递应用的本机认证凭据。
- 模型与密钥页、首次使用引导增加 DeepSeek 账号入口。已有账号授权可通过模型配置门禁，无需另外填写 API Key；返回管理页时刷新账号状态并保留未保存的设置。
- 管理页只读取账号授权记录的存在状态，不回传授权令牌。账号登录与 API Key 配置仍由各自的官方机制管理。

## 升级提示

认证脚本位于 Ubuntu 运行环境中，因此仅覆盖安装 APK 不足以修复已有运行环境。升级后需在应用提示时确认更新运行环境；0.3.1 的版本标记可让已安装 0.3.0 的设备识别此更新，不放宽现有防降级保护。

**更新运行环境会替换其中的本地修改。请先另行备份重要数据；程序的自动保留与恢复机制不能代替完整备份。**

## 验证限制

前端 846 项测试通过；脚本 325 项通过，4 项因平台限制跳过。生产构建与 ESLint 通过，构建保留现有大分块体积警告。

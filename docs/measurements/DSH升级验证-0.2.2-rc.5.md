# DSH 0.2.2-rc.5 升级验证

日期：2026-11-25。

## 改动

- 内置运行时、官方前端与移动插件 peer 从 0.2.1-rc.1 统一升至 0.2.2-rc.5，保留整族精确版本覆盖。
- Cordis 升至 4.1.0、Schemastery 升至 3.19.0，pi-ai 升至上游要求的 1.3.0 并保留工具结果去重补丁。
- 重建三份 DSH 补丁：写入回退适配新的 options 参数；附件发布保留 rename/copy 回退；静态服务适配 Request/Response，并保留上游 ETag 和 304 行为。
- 同步前端子模块指针、两份锁文件、打包默认版本及当前版本文档。应用版本仍为 0.4.6，本次不创建发布标签。

## 验证与边界

- 两个工作区依赖安装通过，运行时生产依赖审计无 high/critical（2 low、3 moderate）。
- 官方前端构建、13 项适配层测试与 12 项运行时锚点校验通过。
- 降级前端通过 Android 10 API 兼容扫描；静态扫描不能替代真机 WebView 回归。
- 真实 Cordis 容器注册 31 个移动工具；真实 DSH 启动冒烟通过：585 个 profile 链接、鉴权入口、无凭据 401、带凭据 200。该验证运行于 Windows，未验证 ARM64 PTY。
- 脚本测试 454 项：452 通过、2 跳过；新增缓存 304/HEAD 断言单独通过。
- Android Kotlin 编译与单元测试通过。SDK 使用已有的 `.android-sdk`，未修改仓库内 SDK 配置。
- 本次暂存内容导出到隔离目录后，类型检查与生产构建通过。
- 开始升级时外壳前端 1124 项测试、类型检查和 lint 通过；后续共享工作区的设置页编辑不属于本次升级。
- 尚未构建 ARM64 rootfs 或安装真机；启动耗时 elapsed_ms 尚无本次真机读数，不据此宣称性能改善。

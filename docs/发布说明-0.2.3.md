## 本次新增

- **目标应用副屏（实验功能）**：在设置中的 AI Shell 区域选择目标应用，尝试在独立虚拟显示上运行，提供原生预览页面和可拖动小窗；两种预览共用会话。
- **AI 副屏工具**：`mobile_virtual_screen_state` 查询状态，`mobile_virtual_screen_screenshot` 获取 PNG，`mobile_virtual_screen_action` 执行点击、滑动、返回和结束会话。画面理解需要支持图像输入的模型。
- **会话管理**：锁屏、熄屏时暂停该通道的读取与输入；授权关闭、Shizuku 断开或宿主死亡时回收资源。会话失效或目标应用离开副屏时明确报错，不回退操作主屏。
- **项目介绍**：首页调整为中文 AI 工作台概览，补充插件导入、文件管理、设备自动化与模型数据去向，保留应用图标和 QQ 群入口。

## 安装与升级

1. 下载该测试版的 `app-release.apk`。安装包内置 Ubuntu 运行环境与本次移动端插件；首次安装运行环境可离线完成。
2. 已安装用户先备份重要会话、工作区和自定义插件数据，再覆盖安装。**仅更新 APK 不会替换已经安装的运行环境，也不会自动改写现有插件数据。**
3. 要使用新的 AI 副屏工具，需要在应用内更新到本版随附运行环境，或更新兼容的 `dsh-mobile-shizuku` 插件。默认内置插件随运行环境更新，不能把旧插件版本误判为工具调用故障。
4. 运行环境更新会替换系统目录，用 apt 等安装的软件和系统目录内的手动修改可能丢失；会话、密钥、附件、默认工作区及应用内安装的插件按项目现有保留规则处理，不能视为任意目录的完整备份。通过终端安装且不在保留范围内的插件需重新安装。
5. 授权 Shizuku 并开启 AI Shell 后，从 **设置 → AI Shell → 目标应用副屏（实验功能）** 选择目标应用；小窗还需悬浮窗权限。

## 已知限制与反馈重点

- 副屏使用限帧 PNG 预览，尚无副屏专用无障碍节点树、中文文本输入、多指手势或高帧率视频流。
- 副屏能否运行取决于系统显示权限和目标应用的多屏支持；安全窗口或受保护内容可能黑屏。普通副屏没有独立焦点保证，不承诺完全不影响主屏交互。
- 本版不保证目标应用在锁屏后可操作、自启动或永久保活。AI 请求截图时，画面可能发送至当前模型服务；本机预览本身不上传图像。
- 请重点反馈：Shizuku 首次授权与重连、应用启动位置、主副屏点击是否分离、横竖屏切换、小窗收起与恢复、结束后是否残留显示。
- 反馈请附设备型号、Android 版本、目标应用及其版本、复现步骤；先移除截图和日志中的个人信息。QQ 交流群：`1108895375`。

# 0.2.4 测试版：副屏输入与截图新鲜度改进

本版尚未发布，用于下一次测试版构建；基线为 `v0.2.3-mobile-323`。

## 改动

- 副屏动作新增受控 `long_press`、`keyevent` 和可打印 ASCII `text`，两端都执行白名单、坐标、时长和长度校验；中文和 emoji 继续使用分享 Intent 或设备输入法。
- 副屏截图返回目标包名、`frameAtElapsedMs` 和 `frameReused`，帮助 AI 区分缓存帧与新帧；静止页面仍可能复用缓存，不承诺高帧率流。
- 文档加入 HONOR AAP-AN00 / Android 17 真机回执，明确记录沙箱执行、硬链接、C 编译器、make、白帧和中文输入限制。

## 未解决的设备限制

- 沙箱内命令和沙箱内 PTY 失败、硬链接被拒绝属于该设备的 PRoot/内核策略限制；应用不会把它们伪报为已修复。
- DSH 副屏预览页前台时可能出现白帧；真实第三方应用、小窗互切、长期后台和锁屏恢复仍需继续验证。
- 目标应用副屏仍没有专用无障碍树；中文文本和剪贴板是否可用取决于设备与目标应用。

## 验证

前端构建、ESLint、设备工具脚本测试通过。Android JVM 单测需要 Gradle Wrapper；当前工作区缺少 `android/gradle/wrapper/gradle-wrapper.jar`，因此本机未伪报通过，需由 CI 或配置完整 Gradle 8.11.1 的环境验证。

# 宣传动画

`index.html` 是一个无需构建工具的 16:9 宣传动画，采用深海蓝、冰蓝与珊瑚色的鲸鱼娘风格视觉，介绍 DSH Mobile 的 Shizuku 通道、投递区文件管理、无障碍自动化和后台保持能力。

打开方式：

1. 双击 `index.html`，或在浏览器中打开它。
2. 点击「开始预览」播放 60 秒动画。
3. 如需配乐，点击「添加已授权音乐」，选择本机拥有公开使用授权的音频文件。页面不会内置或下载歌曲。
4. 使用浏览器录屏、系统录屏或 OBS 录制舞台区域，即可得到宣传视频。

页面支持窄屏预览、键盘焦点、`prefers-reduced-motion`（减少动态效果）设置和离线打开。
